# Recorded ORR performance tables

`table-3138-sample.html` and `table-3124-sample.html` are trimmed extracts of the
Office of Rail and Road data portal pages for Table 3138 (train punctuality at
recorded station stops by operator, periodic) and Table 3124 (trains planned and
cancellations by operator, periodic), recorded on 2026-09-03. Each keeps the
`#reportTable` element with its real column headers and the real rows for
three operators over the two latest periods, so the tests exercise the exact
structure the bounded ORR adapter parses. Page chrome and every other row were
removed; no value was edited.
